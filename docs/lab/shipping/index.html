lab · shipping

Five ways to fold the shipping ledger down so it stops eating the home page. Same rows, same type, same column width as the real page. Only the way they open differs.

all five are CSS only, keyboard reachable, and drop-in for the <Ledger> call on the home page

the fold

The list stays flat and a fold line cuts across it. Four rows sit above, the last one fading into the crease, and the rest are tucked behind it. The toggle moves to the bottom once it opens.
